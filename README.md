# Crônicas & Dados

Portal estático de exemplo para divulgação de mesas de RPG de mesa online, filtro por sistema, rolador de dados rápido e cadastro local de campanhas.

## Como publicar no GitHub Pages
1. Crie um repositório público no GitHub (ex.: `cronicas-e-dados`).
2. Envie `index.html`, `styles.css`, `script.js` e `README.md` para a branch `main`.
3. Vá em **Settings > Pages**.
4. Em **Build and deployment > Branch**, selecione `main` e a pasta `/ (root)`, depois clique em **Save**.
